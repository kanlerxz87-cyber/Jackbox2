Source hierarchy applied

  1. Statutory and regulatory text, or the agency's own page — used for tax rates, thresholds, wage floors, hazard programmes and map products.
  2. Primary filings — the issuer's own Form 8-K exhibits, quoted with the filing date and accession path.
  3. Official statistical series — the agency's published table or the central bank's series identifier, quoted with the period the value refers to.
  4. Nothing else. No aggregator, no press summary, no model output is treated as a source.

Known source limitations

  • Vintage differences. Two official population series disagree by more than 140,000 persons; both are shown, neither is averaged. See F-02.
  • Missing observations. The Los Angeles 12-month CPI change for October 2026 cannot be published; October 2025 was not collected. See the CPI row on the ledger.
  • Unreachable pages. Six official pages did not respond during the sweep; each is listed with its URL so the check can be repeated.
  • Privacy-thin sources. Parcel-level determinations necessarily identify the property, so they are performed in the secure workspace and only the method is published here.
  • Forward-looking statements. Guidance figures are the issuer's own expectations, not results. They are labelled as guidance wherever they appear.

How to re-run this check

  1. Open each source link above and compare the value with the ledger row it supports.
  2. If a value has been revised, update data/root.json and rebuild; the generator will not print a verified value without a source id.
  3. If a source no longer responds, leave the value in place only if it was verified on an earlier date and say so; otherwise blank it and add it to the flagged queue.
  4. Run python3 tests/check_root.py before publishing.
