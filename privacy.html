Privacy and workspace rules

What is published, what is withheld, how the two layers are separated, and the threats this design reduces.

Privacy is the first constraint on this project, not a footnote. The property is identifiable from a street address, a parcel number, or a lease document. Those three things are therefore never published, and the owner's finances never leave the adviser group. What is published is aggregate and non-identifying.

Placeholders used on this site

  • [PARCEL — WITHHELD] — stands in for the address, parcel number and any description that would locate the property.
  • [OWNER — WITHHELD] — stands in for the owner, the holding entity, and any guarantor.
  • [LEASE EXPIRY — 2030–2035 per owner brief — UNVERIFIED] — the expiry window comes from the owner's brief and has not been verified against the lease.

How the workspace is separated

  1. Public layer. This static site. It is generated from a data file that contains no identifiers, so an identifier cannot leak into a page by accident.
  2. Internal layer. The lease abstract, title work, hazard determinations, insurance quotes, broker opinions and tax computation, held by the advisers who need them, under access control.
  3. Transfer rule. Only a value that is both non-identifying and independently verified crosses from the internal layer to the public layer, and it crosses with its source and date.
  4. No upload path. The public site has no form, no upload and no analytics. The calculator runs in the browser and sends nothing.

Operating rules for anyone working on this project

  • Never commit a lease, a rent roll, a tax return, an insurance quote or a parcel identifier to this repository.
  • Never paste such a document into a public issue, a pull request description or a commit message.
  • Use the placeholders above in any page, memo or summary that leaves the adviser group.
  • Run the identifier scan before publishing; it is part of the build, not an optional extra.
  • If an identifier is published by mistake, treat it as an incident: remove it, record it, and tell the owner.

Scope of this policy

This policy governs this repository and the pages published from it. It does not replace the owner's own confidentiality agreements with brokers, tenants, lenders or advisers, and it does not address legal discovery or regulatory requests, which belong with counsel.

Privacy. No owner name, entity, street address, parcel number, lease file or owner financial record appears on this site.
