Limits, stated plainly

  • It ignores depreciation recapture timing rules, installment sales, exchanges and entity-level tax.
  • It assumes a single rent stream and a single exit. It cannot model a partial renewal or a re-tenanting period except through the vacancy field and a lower rent.
  • It assumes the terminal value is achieved exactly at the exit cap rate, which is the most fragile assumption in any real estate model.
  • It is not a back-tested model. A cash-flow model should only be relied on once it has been back-tested against actual outcomes, which requires comparable history this repository does not hold.
