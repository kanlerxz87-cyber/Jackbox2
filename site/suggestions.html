Suggestions and a path to choose

Proposed improvements to this site and to the decision process, none implemented, each with a recommendation so a path can be chosen first.

Nothing on this page has been implemented. That is deliberate. The brief asks for a dedicated section where a reviewer can see suggested improvements and choose a path before anything changes. Every proposal below is a recommendation with its reasoning attached, so the choice can be made on the merits rather than on vibes.

Two suggestions matter more than the rest. SG-07 (the hard verified/unverified visual rule) protects against the failure mode where a polished site becomes a source of false confidence. SG-05 (a comparable-transactions tracker built from public county records) is the only route to a defensible price that does not require buying commercial data. If only two things are done, do those.
