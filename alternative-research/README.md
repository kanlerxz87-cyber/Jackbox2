# Property decision desk

A static, anonymous research dashboard for a net-lease property decision. Open `index.html` locally or deploy with GitHub Pages. No package installation is needed. Run `python3 tests/check.py` to validate local links and source links on table rows.

No private workspace is provided. Do not commit identifying details, lease files, financial records, or private calculator inputs. The calculator performs only arithmetic on supplied adviser outputs, stores nothing, and is not a tax engine. Public evidence is not a property-specific valuation or professional advice. See Flagged for Review for missing inputs and verification limitations.
