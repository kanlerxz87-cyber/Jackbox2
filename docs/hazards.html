Resilience Rule

Stress loss of rent, repairs, and exit liquidity together.

A single hazard event can simultaneously reduce rent, increase capex, raise insurance deductibles, and widen exit cap rates. The private model must run combined scenarios, not isolated best-case sensitivities. No combined-scenario output is published here because property inputs are unverified.

Hazard screening is process guidance only; parcel determinations require authorized internal checks and qualified professionals.
