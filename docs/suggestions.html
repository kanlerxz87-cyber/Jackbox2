Suggested Implementation Order

Best path before any transaction decision.

  1. Lock privacy and internal workspace (P-01–P-06, SG-01). No public parcel data.
  2. Resolve critical unknowns (Q-01 to Q-07): lease abstract, market quotes, after-tax model, hazard/insurance.
  3. Run stress tests (R-01–R-07): combined downside scenarios, not single-point estimates.
  4. Only then compare sell vs. renew/hold at G7 with advisor-reviewed evidence.

Suggestions are for reviewer selection; none are a final recommendation.
