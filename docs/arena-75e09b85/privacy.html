Privacy & Data Handling

Personal information privacy is the top priority. This page defines what is excluded from the public site, how anonymization is applied, and what must remain in secure internal workflows.

No personal data published Aggregate/non-identifying only

Public-Site Privacy Rules

Data category Public site treatment Internal handling Status Policy basis / note
Property address, APN/parcel ID, legal description, coordinates Never published. Replaced by anonymized placeholder: "[SUBJECT PROPERTY - INTERNAL ONLY]". Access-controlled internal workspace only; authorized advisers only. Required control User instruction: anonymize any personal information; no personal information on final website product.
Owner name, entity, contact details, tax IDs, account numbers Never published. No placeholders containing real values. Secure internal workflow only; do not commit to repo. Required control User instruction: personal information privacy top priority/highest urgency.
Lease documents, rent roll, tenant financials, owner financials, tax returns Never published. Only anonymized decision-framework templates may be shown. Offline/secure internal storage with authorized advisers; use private lease abstract. Required control User instruction: keep all parcel and owner records in access-controlled internal workspace; publish only anonymous summaries.
Parcel-level hazard screening outputs Public site provides official tool links and regional context only. No parcel-specific zone determination published. Run privately in secure workflow using parcel location; share only with authorized advisers. Internal workflow required Parcel-level hazard status can be location-revealing when combined with property description.
Neighbourhood/tract-level analysis Public site uses aggregate city/county/regional data. No tract IDs or maps tied to subject property. Select consistent Census tracts and local evidence in secure workflow; publish only non-identifying aggregates. Internal workflow required User instruction: use location only in secure workflow to select consistent Census tracts and local evidence.
Broker quotes, appraisals, lender terms, insurance quotes Never published if identifiable. Public site may describe required quote types only. Obtain and review privately; summarize only anonymized ranges if approved by owner/advisers. Internal workflow required Quotes can contain identifying property/party details.

Anonymization Conventions Used on This Site

Item Public representation Reason Status
Subject property "Subject Property (anonymized): QSR, NNN lease, Central Los Angeles area" Avoids parcel-level identification. Applied
Lease expiration "2030–2035 (exact date withheld; internal only)" Exact date may be identifying in combination with other facts; user provided a window. Applied
Location-specific analysis City/county/regional official data with explicit note that parcel/tract selection is internal. Prevents location leakage while preserving useful context. Applied
Financial/tax inputs Blank placeholders and templates only. No verified private financial data available; prevents fabrication. Applied

Incident Handling

If personal information is discovered during research or repo review, it must not be published, copied into site pages, or included in commit messages. Record the existence of the issue only in a secure internal channel/adviser workflow; on the public site, log a redacted "privacy risk flagged - handled internally" entry if needed.
