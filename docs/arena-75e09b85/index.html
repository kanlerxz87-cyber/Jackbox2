Key Principles

These rules govern every page on this site.

Verification rule. Every table row claiming a value must have an official source link. If a value cannot be confirmed from an official source, it is left blank and flagged as unverified. No values are inferred or fabricated.
Privacy rule. No parcel address, APN, owner identity, lease document, rent roll, tax return, or other personal identifier is published. Location-sensitive analysis (tract selection, parcel hazard zone, neighborhood comps) is performed only in a secure internal workflow.
Decision rule. No sell/renew winner is selected until verified lease, financial, tax, market, hazard, and legal inputs exist. The site provides a decision framework, risk inventory, and evidence checklist.
Black-swan rule. Business-as-usual projections are not sufficient. Earthquake, wildfire, flood, insurance shock, tenant/brand disruption, interest-rate shock, and liquidity stress must be evaluated as downside scenarios.
