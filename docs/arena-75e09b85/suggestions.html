W-03: Decision-Gate Progress Board

A decision may proceed only when required gates are complete with verified evidence. This board is a template; evidence links for internal items must remain in secure workspace.

Gate Decision question Required evidence Status Owner (role) Blocker Reference
DG-001 Privacy Is all personal/parcel/financial data protected? Anonymization review; no identifiers in public repo/site; secure internal storage confirmed. In progress Repo maintainer / security reviewer Ongoing discipline required for future updates. Privacy
DG-002 Lease abstract Are lease economics and deadlines verified? Executed lease, amendments, abstract, option/notice calendar. Blocked Real estate attorney / asset manager Missing verified lease documents. Q-001–Q-004
DG-003 Financials Is NOI/cash flow verified? Rent roll, T-12, NNN reconciliations, reserves, debt terms. Blocked Owner / CPA / property manager Missing verified financial records. Q-005–Q-008
DG-004 After-tax Is sell-vs-hold after-tax comparison verified? CPA/tax counsel model with basis, recapture, taxes, costs, reinvestment assumptions. Blocked CPA / tax counsel Missing tax inputs and professional review. After-tax module
DG-005 Market quotes Is short-lease discount priced from real quotes? 3+ BOVs/buyer indications, lender feedback, comparable closed sales. Blocked Investment sales broker / lender No real quotes available. Q-009–Q-011
DG-006 Parcel hazards Are parcel earthquake/fire/flood/insurance risks screened? FEMA MSC, OSFM/CAL FIRE/local fire, seismic/engineering, insurance quotes. Blocked Risk adviser / engineer / insurance broker Parcel-specific secure workflow not completed. W-04
DG-007 Stress test Does the strategy survive combined downside? Scenario model stressing loss of rent + repairs + insurance + illiquidity. Blocked Analyst / CPA / adviser team Missing inputs and model. Risk Analysis
DG-008 Decision meeting Can sell/renew be selected? Completed gates, verified evidence package, adviser review, owner objectives/risk tolerance documented. Blocked Owner + advisers All prior gates incomplete. Decision Framework

Site & Process Improvement Suggestions

Review these suggestions before implementation. Prioritize privacy, verification, and decision quality over feature complexity.

ID Suggestion Expected benefit Risk / caution Priority Review status Reference
SUG-001 Create a secure internal "evidence locker" index (not in public repo) mapping each decision-gate item to verified documents. Makes audit trail clear; prevents missing-input drift. Must never be committed to public repo; access control required. High Needs review Privacy
SUG-002 Add a versioned assumption register for any cash-flow model (date, author, assumption, range, source, confidence). Separates observations from assumptions; improves back-testing discipline. Assumptions can be mistaken for facts if not labeled. High Needs review Model governance
SUG-003 Build a private parcel-screening checklist workflow for FEMA, OSFM/CAL FIRE, USGS/seismic, insurance, and local planning. Completes W-04 with reproducible evidence. Parcel-specific outputs must remain internal. High Needs review W-04
SUG-004 Add a broker/lender quote comparison table (anonymized) with date, term remaining, cap rate, financing assumptions, and confidence. Prices short-lease discount from real quotes instead of heuristics. Quotes may be stale or biased; require multiple sources. High Needs review Q-009
SUG-005 Add automated link-check and "last verified" date badges to source rows in the static site. Reduces link rot and stale-source risk. Automation should not overwrite human verification status. Medium Needs review Source registry
SUG-006 Create a redacted advisor packet export (PDF/print) generated from verified internal data only. Supports W-10 while keeping public site anonymized. Export pipeline must have privacy checks; no accidental identifier leakage. Medium Needs review W-10
SUG-007 Add scenario sliders to the browser calculator for cap rate, vacancy/loss-of-rent, repair cost, and hold period. Improves sensitivity understanding for users. Can create false precision; keep "illustrative only" warnings prominent. Medium Needs review Calculator
SUG-008 Add a change log/data provenance section showing when each source was checked and by whom (session/role). Improves accountability and auditability. Do not include personal names/contact details in public log. Medium Needs review Sources

Suggestions are for review; no implementation should bypass privacy or verification controls. Flagged for Review.
