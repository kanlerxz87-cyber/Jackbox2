Suggestions

Fifteen proposals, ordered by whether delay has a cost — with the site changes left unimplemented so they can be reviewed first.

Nothing on this page has been implemented. These are proposals, written so they can be reviewed, argued with and chosen one at a time. The site changes are described here rather than built, because the owner asked to review suggestions before anything is implemented.

How to choose

  1. Start with the four that protect optionality (S-01 to S-04). They are low effort, high impact, and they are the only ones where delay has a cost.
  2. Then the three that produce the number (S-03, S-07, S-08). Without them there is no comparison, only an opinion.
  3. Then governance (S-09, S-10). They cost nothing and stop the decision drifting.
  4. Site changes last (S-11 to S-13). They improve how the evidence is maintained, not what the evidence says.

What a reliable projection system would require

The brief asks for a deep, reliable projection system for the area. That is a reasonable ambition and it has preconditions that are not yet met. A model that could be trusted would need:

  1. A target with history. Store-level sales for this unit, or failing that, a comparable set of drive-through units with five or more years of observations.
  2. Predictors measured at the same geography and frequency. Tract or ring-level population, income, employment and traffic, not county proxies.
  3. Back-testing. Fit on the earlier period, predict the later one, and report the error honestly. A model that has never been back-tested is a hypothesis.
  4. Explicit separation of observation and assumption. Every input labelled as one or the other, so a reader can see which part of the output is evidence.
  5. Versioning. Each run dated, with its inputs, so a later reader can reproduce it.
Proposed rule. Do not publish a point forecast for this parcel until items 1 to 3 are satisfied. Until then, publish scenario ranges labelled as assumptions, which is what this site does.
