Audit scope P-01 · 2026-11-26

Public-site integrity audit

This page distinguishes a local build-and-provenance check from verification of a property fact. A working link or an allowed government domain is not proof that a private lease, parcel, owner financial record, quote, or tax calculation is correct. Those items stay blank and are flagged.

Current public dashboard: Central LA 2026 Refresh No outcome selected Legacy copies are not current decision surfaces

What this audit checks

Privacy signals

Scans public HTML, JSON, CSS, JavaScript, and Markdown for common SSN, email, phone, ZIP, street-address, and parcel-number patterns. It is a safety net, not a guarantee that every sensitive fact is detectable by regex.

Link integrity

Checks local targets and anchors, blocks insecure HTTP and browser-facing localhost links, and reports direct official-source-link coverage in static tables.

Current dashboard behavior

The Central LA dashboard’s own verifier validates its JSON records and trusted domains; its runtime test confirms each dynamically rendered table row contains an HTTPS source link.

Honest boundary

No automated public check can validate private lease terms, parcel zone status, broker quotes, tax basis, or owner objectives. Those remain decision gates, not assumptions.

Decision rule remains unchanged

Do not select sell, renew, or hold from public context alone. A defensible choice requires verified private inputs and aligned dates: lease abstract and notice calendar, tenant/guarantor obligation, rent and capex obligations, parcel-level hazards and insurance, broker bids and renewal terms, owner tax basis/depreciation/entity facts, debt/reinvestment constraints, and written owner objectives.

Review-before-implement improvement path

Review proposed enhancements before adding any data or features. The current Suggestions page includes the secure trade-area workflow, versioned cash-flow model, broker-quote tracker, and hazard-screening improvements—none should publish private information.
